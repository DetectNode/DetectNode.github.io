Privacy-first edge AI for Axis cameras

Computer vision on the camera. Privacy by design.

DetectNode is an ACAP application that runs computer vision models on your Axis camera, so the analysis stays local. You choose what DetectNode sends: measurements, events or images.
No cloud account or extra server costs.

Analyses

Eight premade analyses.

Pick a preset, choose the classes to watch, and draw the area.
Each analysis returns a value your systems can use.

Detect

Line crossing

Detect objects crossing a line, with separate in and out counters.

ReturnsIN 12 / OUT 9

Example Doors, gates, conveyors, roads.

Detect

Presence / loitering

Detect objects dwelling in a zone for longer than a chosen duration.

Returns2 objects

Example Restricted areas, queues, platforms.

Measure

Level / Height

Measure a level or height from a surface line, calibrated in real-world units.

Returns1.84 m

Example Tanks, rivers, canals, silos.

Measure

Zone coverage

Measure how much of a zone is covered by the selected classes or mask.

Returns64 %

Example Flood zones, parking, storage, waste bins.

Measure

Peak height

Track the highest — or lowest — relative point of a region over time.

Returns0.42 rel.

Example Stockpiles, truck loads, pallets.

Measure

Object counting

Count separate objects or blobs, with size filters to ignore noise.

Returns12 objects

Example Vehicles, pallets, people, products.

Logic

Custom logic

Combine measurements and raw inputs into your own condition.

ReturnsON / OFF

Example Level + presence + count, with a duration.

Anomaly

Anomaly score

Learn a normal scene with PaDiM and score anything that does not fit.

Returns12.4 %

Example Fixed industrial scenes, unknown defects.

FAQ

Does it work offline?

Yes. Analysis and rules run on the camera. Internet is only needed to download models or updates.

Which cameras are supported?

DetectNode is an ACAP application for Axis cameras with ARTPEC-8 or ARTPEC-9, running AXIS OS 12.10 – 13.x.

Can I use my own model?

Yes. ONNX on the CPU or TFLite on the DLPU. Detection, segmentation and anomaly models are supported.

What is a signed model?

A .detectnode package signed with a private key. A public key baked into the app verifies it on upload, and a green badge confirms it.

Are any models included?

No. Models are not included with the app, but you'll find a link in the app to try some models.

Is this production-ready?

No. It is a personal project in active development, provided as a trial pre-release. It is not industrial or production-ready, and comes with no warranty.
